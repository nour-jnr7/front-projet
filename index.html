Toute instruction CSS repose sur une syntaxe simple mais précise. En comprendre chaque composant, c'est éviter 80 % des erreurs de débutant.

La syntaxe de base

Une règle CSS = un sélecteur + un bloc de déclarations. Le bloc contient des paires propriété : valeur.

/* Anatomie complète */
sélecteur {
  propriété: valeur;
  propriété: valeur;
}
⚠️ Erreurs fréquentes
  • Oublier le point-virgule — la déclaration suivante est ignorée
  • Écrire color blue au lieu de color: blue
  • Confondre les guillemets dans les valeurs de chaîne

Où peut-on écrire du CSS ?

✅ Feuille de style externe (recommandé)

<!-- Dans le HTML -->
<link rel="stylesheet" href="style.css">

/* Dans style.css */
body { margin: 0; }

Séparation HTML/CSS — maintenable, mis en cache par le navigateur.

⚠️ Balise <style> (acceptable)

<style>
  p { color: blue; }
</style>

Utile pour les petits projets ou les prototypes.

❌ Style inline (à éviter)

<p style="color: red; font-size: 16px;">Texte</p>

Spécificité maximale, non réutilisable, impossible à maintenir. Réservé aux cas extrêmes (emails HTML, JS dynamique).

Section 02

Cascade, Spécificité & Héritage

CSS = Cascading Style Sheets. La cascade est le mécanisme central qui détermine quelle règle s'applique quand plusieurs règles ciblent le même élément.

🌊

La cascade

Quand deux règles ciblent le même élément, le navigateur les départage dans cet ordre de priorité :

  1. Origine — Styles du navigateur < Styles auteur < !important
  2. Spécificité — Score calculé selon le type de sélecteur
  3. Ordre source — La dernière règle l'emporte (à spécificité égale)
ℹ️ À retenir La cascade ne signifie pas « la dernière règle gagne toujours ». La spécificité prime sur l'ordre.
🧬

L'héritage

Certaines propriétés CSS se transmettent automatiquement des parents vers les enfants :

✅ Propriétés héritées color, font-family, font-size, line-height, letter-spacing, text-align…
❌ Propriétés non héritées margin, padding, border, width, background, display… 
body { font-family: Arial; }
/* Tous les enfants héritent de font-family */

div { color: inherit; }
/* Forcer l'héritage d'une propriété */

Section 03

Types de sélecteurs CSS

Les sélecteurs sont le langage de ciblage du CSS. Maîtriser l'ensemble du spectre — des plus simples aux plus modernes — est ce qui distingue un développeur CSS compétent.

Sélecteurs fondamentaux

* — Universel
Cible tous les éléments
Utilisé pour les resets CSS. Éviter pour des styles complexes (coût de performance).
* { box-sizing: border-box; }
p — Élément (type)
Cible tous les éléments d'un type HTML
Affecte TOUS les paragraphes, TOUS les liens, etc. Utile pour les styles de base.
a { text-decoration: none; }
h2 { font-weight: 700; }
.classe — Classe
Cible les éléments avec cet attribut class
Le plus utilisé en pratique. Réutilisable, faible spécificité. Préférez toujours les classes aux IDs.
.btn { padding: .5rem 1rem; }
.btn.active { background: blue; }
#id — Identifiant
Cible l'élément unique avec cet id
Spécificité très haute. Un ID doit être unique sur la page. À éviter pour le styling, préférez les classes.
#main-nav { display: flex; }
[attr] — Attribut
Cible selon la présence ou valeur d'un attribut
Très puissant pour styler des éléments de formulaire ou des liens externes sans ajouter de classes.
[disabled] { opacity: .4; }
[type="email"] { border: 2px solid blue; }
[href^="https"] { /* commence par */ }
[href$=".pdf"]  { /* se termine par */ }
[class*="btn"] { /* contient */ }
:pseudo-classe
Cible un état particulier d'un élément
États dynamiques, position dans le DOM, interaction utilisateur.
a:hover          /* survol */
input:focus       /* focus clavier */
li:first-child    /* 1er enfant */
li:last-child     /* dernier enfant */
li:nth-child(2n)  /* lignes paires */
p:not(.special)  /* négation */
:checked          /* case cochée */
:valid / :invalid /* validation form */
::pseudo-élément
Cible une partie d'un élément
Permettent de styler des parties virtuelles ou d'insérer du contenu généré sans toucher au HTML.
p::before        /* contenu avant */
p::after         /* contenu après */
p::first-line    /* 1re ligne */
p::first-letter /* 1re lettre */
::selection     /* texte sélectionné */
::placeholder   /* placeholder input */

Sélecteurs modernes CSS4

:is() — Groupement intelligent
Réduit la répétition, ignore les sélecteurs invalides
Équivalent à une liste de sélecteurs, mais plus maintenable. La spécificité est celle du plus spécifique à l'intérieur.
/* Avant :is() — verbeux */
h1 a, h2 a, h3 a, h4 a { color: blue; }

/* Avec :is() — élégant */
:is(h1, h2, h3, h4) a { color: blue; }
:where() — Sans spécificité
Comme :is() mais spécificité toujours = 0
Idéal pour les resets et bibliothèques CSS qui ne doivent pas imposer de spécificité.
/* Spécificité = 0 (0,0,0,0) */
:where(.card, .modal, .popup) {
  border-radius: 8px;
}
:has() — Parent selector
Le sélecteur parental tant attendu
Révolutionnaire : cible un élément selon ce qu'il contient. Support navigateurs ≥ 2023.
/* Carte qui contient une image */
.card:has(img) {
  display: grid;
  grid-template-columns: 1fr 2fr;
}
/* Form avec champ invalide */
form:has(:invalid) { border-color: red; }

⬇️

Descendant A B

Sélectionne tous les B à l'intérieur de A, qu'ils soient enfants directs ou profondément imbriqués.

nav a { color: white; }
/* Cible TOUS les <a> dans <nav>
   peu importe leur niveau */

.card p { line-height: 1.6; }
PerformanceLe navigateur lit les sélecteurs de droite à gauche. div p cherche d'abord tous les p, puis filtre ceux dans div. Sur des DOM profonds, ça peut coûter.
▶️

Enfant direct A > B

Sélectionne les B qui sont des enfants immédiats de A uniquement. Beaucoup plus précis et performant.

ul > li { list-style: square; }
/* Les <li> dans une <ul> imbriquée
   ne sont PAS affectés */

.navbar > .menu { display: flex; }
Bonne pratiquePréférez > à l'espace quand vous connaissez la profondeur exacte. C'est plus rapide et plus explicite.
➡️

Frère adjacent A + B

Sélectionne B immédiatement après A, s'ils partagent le même parent.

h2 + p {
  font-size: 1.1rem;
  margin-top: 0;
}
/* Le paragraphe qui suit immédiatement
   un titre prend une mise en forme spéciale */

input:checked + label {
  color: green;
}
⟶

Frère général A ~ B

Sélectionne tous les B frères qui suivent A (même parent, pas forcément adjacents).

h2 ~ p { color: var(--muted); }
/* Tous les <p> après un <h2>,
   pas seulement le premier */

/* Astuce : Toggle CSS sans JS ! */
#menu-toggle:checked ~ .menu {
  display: block;
}
Astuce avancéeLe combinateur ~ combiné à :checked permet de créer des menus, accordéons et onglets entièrement en CSS, sans JavaScript !

Noms de couleurs

CSS reconnaît 140 noms prédéfinis. Pratiques à écrire mais peu précis.

color: red;
background: cornflowerblue;
border-color: transparent; /* ← très utile !
#

Hexadécimal

Format le plus utilisé. Chaque paire de chiffres hex représente un canal (RR, GG, BB).

color: #ff0000;    /* R=255 G=0 B=0 */
color: #f00;       /* raccourci = #ff0000 */
color: #336699;   /* bleu ardoise */
color: #33669980; /* + opacité 50% (8 dig.) */
Comment lire #58a6ff#58=88 rouge · a6=166 vert · ff=255 bleu. Plus la valeur est haute (ff=255), plus ce canal est intense.
🔴🟢🔵

RGB & RGBA

Valeurs de 0 à 255 pour chaque canal. rgba() ajoute un 4e canal : l'alpha (opacité, de 0 à 1).

color: rgb(255, 0, 0);
background: rgba(0, 0, 0, 0.5);
/* Superposition semi-transparente */

/* Syntaxe moderne (CSS4) */
color: rgb(255 0 0 / 50%);
💡 Quand utiliser rgbaOverlay sur des images, effets de verre (glassmorphism), ombres colorées, éléments flottants.
🌈

HSL & HSLA

Hue (0-360°) · Saturation (0-100%) · Lightness (0-100%)

color: hsl(0, 100%, 50%);    /* rouge */
color: hsl(120, 100%, 50%);  /* vert */
color: hsl(240, 100%, 50%);  /* bleu */

/* Variations simples : même teinte */
--light: hsl(213, 100%, 80%);
--base:  hsl(213, 100%, 60%);
--dark:  hsl(213, 100%, 40%);
💡 Avantage HSLPour créer des palettes cohérentes : gardez H fixe, jouez sur S et L. C'est impossible avec RGB/HEX.
🚀

OKLCH — Le futur des couleurs CSS Moderne

OKLCH (Lightness, Chroma, Hue) est l'espace colorimétrique le plus avancé disponible en CSS moderne. Il accède à une gamme de couleurs bien plus large (wide color gamut) que RGB/HSL et garantit une luminosité perceptuellement uniforme.

/* oklch(luminosité% chroma teinte) */
color: oklch(68% 0.2 213);   /* bleu vif */
color: oklch(55% 0.22 142);  /* vert éclatant */
color: oklch(50% 0 0);       /* gris neutre */

/* Couleurs P3 impossibles en sRGB ! */
color: oklch(75% 0.3 140); /* vert plus vif que #00ff00 */
✅ Avantages OKLCHLuminosité perceptuellement uniforme — les palettes générées semblent toujours cohérentes. Accès aux couleurs P3 des écrans Apple/HDR. Manipulation intuitive.
⚠️ CompatibilitéSupporté sur tous les navigateurs modernes (Chrome ≥ 111, Firefox ≥ 113, Safari ≥ 15.4). Utilisez un fallback HEX pour les très vieux navigateurs.
Section 06

Variables CSS (Custom Properties)

Les variables CSS sont l'une des fonctionnalités les plus puissantes du langage moderne. Elles permettent de créer des systèmes de design maintenables et du theming dynamique.

📦

Déclaration et utilisation

/* Déclaration dans :root = portée globale */
:root {
  --primary:   #58a6ff;
  --secondary: #bc8cff;
  --font-base: 'Outfit', sans-serif;
  --spacing-sm:0.5rem;
  --radius:    10px;
}

/* Utilisation avec var() */
.btn {
  background:    var(--primary);
  font-family:   var(--font-base);
  padding:       var(--spacing-sm) 1rem;
  border-radius: var(--radius);
}

/* Valeur de fallback */
color: var(--accent, #58a6ff);
🌙

Dark mode avec variables

Les variables CSS sont la solution idéale pour le theming — une seule variable suffit à tout changer.

:root {
  --bg:   #ffffff;
  --text: #1f2328;
}

/* Thème sombre automatique */
@media (prefers-color-scheme: dark) {
  :root {
    --bg:   #0d1117;
    --text: #e6edf3;
  }
}

/* Thème via attribut (toggle JS) */
[data-theme="dark"] {
  --bg: #0d1117;
}
🔗

Portée locale et composition

Les variables peuvent être redéfinies localement — elles ne s'appliquent qu'aux descendants.

/* Redéfinition locale */
.danger-zone {
  --primary: #f85149;
}
/* Tout dans .danger-zone utilise le rouge */

/* Composition de variables */
:root {
  --hue:    213;
  --color-base: hsl(var(--hue), 80%, 60%);
  --color-dark: hsl(var(--hue), 80%, 40%);
  --color-glow: hsl(var(--hue) 80% 60% / 30%);
}
💡 Technique avancéeStockez la teinte HSL dans une variable numérique et composez toute une palette à partir d'une seule valeur.
✅

Bonnes pratiques

  • Nommez vos variables de manière sémantique, pas par leur valeur : --color-primary plutôt que --blue
  • Créez un design token system : couleurs → espacements → typographie → ombres
  • Groupez vos variables dans :root en haut du fichier
  • Utilisez des valeurs de fallback : var(--primary, #58a6ff)
  • Les variables CSS peuvent être animées avec @property
ℹ️ Variables ≠ préprocesseurContrairement aux variables SASS/LESS, les variables CSS sont dynamiques — elles peuvent être modifiées par JavaScript en temps réel : document.documentElement.style.setProperty('--primary', '#f00')

❓ FAQ — Questions fréquentes

Quelle différence entre classe et ID pour le styling ?

Les classes (.nom) sont réutilisables, composables et ont une spécificité modérée → idéales pour le styling. Les IDs (#nom) doivent être uniques et ont une spécificité très élevée → difficiles à surcharger. En CSS, utilisez toujours les classes. Reservez les IDs pour les ancres de navigation et JavaScript.

Pourquoi mes styles ne s'appliquent pas ?

Vérifiez dans cet ordre :

  1. Syntaxe — point-virgule manquant ? Deux-points au lieu de point-virgule ?
  2. Sélecteur — correspond-il réellement à l'élément HTML ?
  3. Spécificité — une règle plus spécifique l'emporte sur la vôtre
  4. Ordre source — à spécificité égale, la règle définie en dernier gagne
  5. Cache navigateur — Ctrl+Shift+R pour recharger sans cache
HSL ou RGB — quand utiliser lequel ?

HSL est plus intuitif pour créer des variations de couleur : gardez H fixe, jouez sur S et L pour obtenir des tons plus clairs/sombres/grisés. RGB/HEX est pratique pour copier-coller des couleurs exactes depuis Figma/Photoshop. OKLCH est la solution moderne pour les systèmes de design car sa luminosité est perceptuellement uniforme.

Comment créer un dark mode sans JavaScript ?

Utilisez la media query @media (prefers-color-scheme: dark) combinée à des variables CSS :

:root { --bg: white; --text: black; }
@media (prefers-color-scheme: dark) {
  :root { --bg: #0d1117; --text: #e6edf3; }
}

Le navigateur applique automatiquement le thème selon les préférences système de l'utilisateur.

Quelle est la différence entre :is() et :where() ?

Les deux acceptent une liste de sélecteurs, mais :is() adopte la spécificité du sélecteur le plus spécifique à l'intérieur (ex: :is(#id, .cls) a une spécificité de ID). :where() a toujours une spécificité de 0 — idéal pour les styles de base facilement surchargeables.
